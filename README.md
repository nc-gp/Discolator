# Discolator
A fake game activity for discord quests.

## Key Features
- Fully working game simulation.
- Works through folder paths.
- Automatically deletes fake exe when game stops.
- A refreshable list directly from discord API (downloadable).
- Auto stop after x minutes.
- Hiding taskbar button.

## How to use
You can either:
- Download the release.
- Run, and enjoy!

or compile it by urself.
